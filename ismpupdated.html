        Guide

        These query parameters are read once when the page loads. Join them with & like any query string; percent-encode a value if it contains & or ? itself.

        • ?guide

          Presence (any value) shows this section so you can link to documentation.

        • ?s=mcc | modrinth.mp | modrinth.mod | guide

          Scrolls smoothly to that main section. mcc is the MinecraftCustomClient modpacks block; guide scrolls here when this section is visible (add ?guide).

        • ?mccmp=name | id | *latest

          Pre-selects a modpack matching flavor name or id (case-insensitive); value may be URL-encoded. *latest picks the first row after the usual Minecraft-version / name sort. Respects “Show hidden”: hidden modpacks are excluded unless that box is on or ?mccshowall=true.

        • ?mcver=version | *latest

          Pre-selects that Minecraft version in the dropdown (exact id from the manifest). *latest selects the first option in the current list (releases only unless snapshots are enabled). If the version is missing, snapshots are turned on once and the list is rebuilt.

        • ?mccnonrel

          Presence flag: checks “Snapshots” before the version list is first filled so pre-releases appear in the version picker.

        • ?mccauto

          Presence flag: after other boot logic, programmatically runs the compatibility check if the button is enabled (modpack + version both set).

        • ?mccshowall=true | 1 | yes

          Checks “Show hidden” so modpack flavors with hidden: true are listed (comparison is strict true on the flavor object).

        • ?homeurl=URL

          Adds a right-aligned MCC Web header link. URL is http(s), same-site relative, or multiply percent-encoded; javascript: / data: blocked. Opens in a new tab.

        • ?backurl=URL

          Same URL rules as homeurl. Shows Go Back (same tab). With both params, Go Back sits to the left of MCC Web.

        • ?ui.mccnohidden=true | 1 | yes

          Hides the “Show hidden” checkbox UI; you can still include hidden modpacks via mccshowall.

        • ?ui.mccnosnap=true | 1 | yes

          Hides the “Snapshots” checkbox UI; mccnonrel can still enable snapshot versions.

        • ?showdown

          Presence flag: shows Attempt download beside Check Compatability in the MinecraftCustomClient Modpacks section, plus Filter libs (unless ui.nofilterlibs) and Prism profile (unless ui.noprismdown). The default zip has mods_{version}/, skipped_{oldver}/, notupdated_{oldver}/, and four-space-indented metadata.json. Filter libs puts Modrinth library projects in a library subfolder. Prism profile instead builds a MultiMC/Prism instance zip (instance.cfg, mmc-pack.json, .minecraft/mods/) containing only mods updated for the selected version. If every other mod pins the same dependency version, that file is downloaded. If they pin different versions, a dialog asks which one to use; All versions opens a dropdown of every Modrinth file for the selected Minecraft version.

        • ?ui.nofilterlibs=true | 1 | yes

          Hides the Filter libs checkbox that ?showdown would otherwise show. Library mods stay in the main mods_, skipped_, and notupdated_ folders.

        • ?ui.noprismdown=true | 1 | yes

          Hides the Prism profile checkbox that ?showdown would otherwise show. When that box is checked together with Filter libs, library mods that are still a dependency of another mod in the pack are left out; a library is still packed if nothing depends on it, or if the pinned dependency no longer supports the selected version but the library itself has an update.
